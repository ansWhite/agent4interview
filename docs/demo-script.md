# 五分钟面试演示脚本

1. 用 30 秒说明问题：Agent 能跑不等于可靠，项目关注状态、证据、预算和评测。
2. 输入一个需要组合架构、检索和安全知识的问题，展示 planner 生成子任务。
3. 展示 SSE 轨迹、每一步预算消耗、混合检索分数和最终引用。
4. 加入一段本地知识，再运行问题，说明摄取、chunk 和索引链路。
5. 运行内置评测，展示 Recall@K、MRR、nDCG、引用指标和任务成功率。
6. 打开消融实验表，解释 RRF 的收益及延迟代价。
7. 最后展示一次不可回答样本或工具故障，说明系统如何有界失败而不是编造或无限循环。

重点技术追问准备：

- 为什么 RRF 适合融合不同分数量纲？
- 为什么 verifier 不能完全依赖 LLM-as-Judge？
- 并发任务下事件序列与状态如何保持一致？
- 何时从模块化单体拆为 worker 和独立 MCP 服务？
- Prompt Injection 如何穿过检索层，工具权限如何阻断实际影响？
